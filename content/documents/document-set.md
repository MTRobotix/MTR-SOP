## Fill in a template

1. Download the Word or Excel file in the customer's language.
2. Replace every blue placeholder in square brackets, then set that text to black.
3. Give the document its number, see [Numbering and filing](#numbering-and-filing).
4. Save as PDF with the same file name and send the PDF.
5. Scan the signed copy to the shared project folder.

> [!WARNING]
> Never put filled or signed documents in this SOP. They contain customer data.

Expected: one PDF per document, numbered, with no blue text left.

## Numbering and filing

- Number format: `CODE-YYYY-NNN`, one sequence per code per year, starting at `001`.
- Codes: `RF` requirements form, `SV` site visit report, `P` proposal, `Q` quotation, `NDA`, `OC` order confirmation, `BOM`, `PO` purchase order, `CO` change order, `MM` minutes, `TR` test record, `AC` acceptance certificate, `DN` delivery note, `PR` payment request, `WC` warranty certificate, `SR` service report.
- All documents of one project carry its proposal number `P-YYYY-NNN`.
- Revisions: rev 0 on first issue, then rev 1, 2. A signed document is never edited; issue a new revision.
- File name: `NN-CODE-YYYY-NNN-customer.pdf`, for example `05-Q-2026-004-customer.pdf`.

Source: templates drafted by Claude with Thong Huynh, November 2026.

## Change a template

1. Download the Word or Excel file from [Which document when](#which-document-when).
2. Edit it and save it as PDF with the same name.
3. Replace both files in `content/documents/attachments/`.
4. Make the same change in the other language.
5. Set `updated:` in this doc and commit.

> [!NOTE]
> The two full-set PDFs are built from the single files. Rebuild them after a change, or note in the commit that they are out of date.
